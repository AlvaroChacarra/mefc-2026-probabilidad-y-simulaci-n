Objetivo¶

Sea X~N(0,1). Consideramos dos transformaciones definidas a tramos, Y=g(X) y Z=h(X):

g(x)={−xx<0αxx≥0h(x)={−xx<0xx≥0

Se pide:

  1. (2.1) Obtener por simulación la densidad fY(y) para α∈{−1,−0.5,0,0.5,1}, compararla con la normal y discutir para qué valores de α es Y continua (casos α=0 y α=1).
  2. (2.2) Para α>0, derivar analíticamente fY(y) mediante P(Y<y).
  3. (2.3) Demostrar que fZ(z)=12π(2ze−z4/2+e−z2/2) y comprobarlo por simulación.

Reproducibilidad. Se usa una semilla fija y todas las afirmaciones numéricas proceden de las celdas ejecutadas.

    "font.size": 11,
    "axes.grid": True,
    "grid.alpha": 0.3,

# ── Constantes del problema ──────────────────────────────────────────────────
SEED   = 42
N_SIM  = 1_000_000               # muchas muestras ⇒ histogramas nítidos
ALPHAS = [-1.0, -0.5, 0.0, 0.5, 1.0]

# ── Muestra base X ~ N(0,1) (se reutiliza en todo el notebook) ───────────────
rng = np.random.default_rng(SEED)
X = rng.standard_normal(N_SIM)

# ── Funciones del problema ───────────────────────────────────────────────────
def phi(x):
    """Densidad N(0,1)."""
    return np.exp(-x**2 / 2) / np.sqrt(2 * np.pi)

Phi = norm.cdf                    # función de distribución N(0,1)

def g(x, alpha):
    """Y = g(X): -x si x<0 ; alpha·x si x>=0."""
    return np.where(x < 0, -x, alpha * x)

def h(x):
    """Z = h(X): -x si x<0 ; sqrt(x) si x>=0."""
    return np.where(x < 0, -x, np.sqrt(np.clip(x, 0, None)))

print(f"X ~ N(0,1) con {N_SIM:,} muestras (semilla {SEED})")
print(f"media muestral = {X.mean():.4f}, desv. típica = {X.std():.4f}")

Apartado 2.1 — Densidad de Y=g(X) por simulación¶

Cómo actúa la transformación¶

g trata por separado las dos mitades de X (cada una con probabilidad 1/2):

  • Rama x<0: Y=−x>0. Esta mitad siempre se envía al semieje positivo, sea cual sea α.
  • Rama x≥0: Y=αx. El signo y la escala dependen de α:
    • α>0⇒Y≥0 (toda la masa en y≥0).
    • α<0⇒Y≤0 (esta mitad va al semieje negativo).
    • α=0⇒Y=0 para todo x≥0: aparece un átomo en 0 con probabilidad 1/2.

Dos casos notables que la simulación debe reflejar:

  • α=−1: entonces g(x)=−x en ambas ramas, luego Y=−X~N(0,1) exactamente.
  • α=1: entonces g(x)=|x|, luego Y=|X| es una media normal (half-normal).

Simulamos Y para cada α, estimamos su densidad con un histograma y la comparamos con N(0,1).

Continuidad de Y: evidencia cuantitativa¶

Una variable es (absolutamente) continua si no tiene átomos. El único valor de α que crea un átomo es α=0 (la rama x≥0 colapsa en y=0). Lo medimos, y de paso confirmamos numéricamente el caso α=−1.

In [3]:

    p0 = np.mean(g(X, a) == 0.0)

# Caso α=-1: contraste formal con N(0,1) mediante Kolmogórov–Smirnov

print(f"\nα = -1:  test KS de Y frente a N(0,1) → D = {ks_m1.statistic:.5f} "
      f"(distancia ínfima ⇒ Y ≡ N(0,1))")

Respuesta al apartado 2.1¶

  • ¿Para qué α es Y continua? Para todo α≠0. La rama x<0 aporta una densidad suave en y>0 y la rama x≥0 (si α≠0) reparte su masa de forma continua (en y>0 si α>0, en y<0 si α<0). No hay átomos.
  • Caso α=0: la rama x≥0 envía toda su probabilidad (1/2) al punto y=0. Aparece un átomo P(Y=0)=12, de modo que Y es mixta (no continua): una masa puntual en 0 más una parte continua ϕ(y) en y>0.
  • Caso α=1: g(x)=|x|, así que Y=|X| es una media normal; ambas ramas se suman y dan la densidad continua fY(y)=2ϕ(y) en y>0 (lo confirmamos en 2.2).
  • Comparación con la normal: solo α=−1 reproduce N(0,1) (porque g(x)=−x); para el resto la densidad de Y difiere claramente de la normal.

Apartado 2.2 — Densidad analítica de Y para α>0¶

Para α>0 ambas ramas envían la masa a y>0, luego Y solo toma valores positivos. Seguimos la sugerencia: escribir P(Y<y) y derivar.

Para y>0, el suceso {Y<y}={g(X)<y} se descompone según la rama:

{Y<y}={x<0, −x<y}⏟−y<x<0 ∪ {x≥0, αx<y}⏟0≤x<y/α={−y<X<yα}

Por tanto,

P(Y<y)=Φ(yα)−Φ(−y)=Φ(yα)+Φ(y)−1

donde hemos usado Φ(−y)=1−Φ(y). Derivando respecto de y (regla de la cadena):

fY(y)=ϕ(y)+1αϕ(yα)=12π(e−y2/2+1αe−y2/(2α2)),y>0

Comprobaciones: el primer término ϕ(y) procede de la rama x<0 (con jacobiano 1) y el segundo 1αϕ(y/α) de la rama x≥0 (jacobiano 1/α). Para α=1 se obtiene fY(y)=2ϕ(y), la media normal anticipada. La densidad integra 1 porque cada término aporta 1/2.

In [4]:
def fY_pos(y, alpha):
    """Densidad analítica de Y para alpha>0 (soporte y>0)."""
    y = np.asarray(y, float)
    return np.where(y > 0, phi(y) + (1/alpha) * phi(y/alpha), 0.0)

# Verificación 1: la densidad integra 1 en (0, ∞)
print("Verificación de la densidad analítica (α>0):")
for a in [0.5, 1.0]:
    val, _ = integrate.quad(lambda y: fY_pos(y, a), 0, np.inf)
    # Verificación 2: distancia KS entre la simulación y la CDF teórica
    F = lambda y, a=a: Phi(y/a) + Phi(y) - 1
    ks = kstest(g(X, a), F)
    print(f"  α = {a}:  ∫₀^∞ fY dy = {val:.6f}   |   KS vs simulación: D = {ks.statistic:.5f}")

Apartado 2.3 — Densidad de Z=h(X)¶

Ahora h(x)=−x si x<0 y h(x)=x si x≥0. Ambas ramas producen valores no negativos, así que Z>0 (salvo el punto X=0, de probabilidad nula). Procedemos igual que en 2.2: P(Z<z) y derivar.

Para z>0:

{Z<z}={x<0, −x<z}⏟−z<x<0 ∪ {x≥0, x<z}⏟0≤x<z2={−z<X<z2}

P(Z<z)=Φ(z2)−Φ(−z)=Φ(z2)+Φ(z)−1

Derivando respecto de z (la rama x da ddzΦ(z2)=2zϕ(z2)):

fZ(z)=2zϕ(z2)+ϕ(z)=12π(2ze−z4/2+e−z2/2),z>0

que es exactamente la expresión del enunciado. ∎

El primer término 2zϕ(z2) proviene de la rama x (jacobiano 2z) y el segundo ϕ(z) de la rama −x (jacobiano 1). Como comprobación de que fZ es una densidad, integra 1 — y cada término aporta exactamente 1/2, las dos mitades de X:

∫0∞2zϕ(z2)dz=u=z2∫0∞ϕ(u)du=12,∫0∞ϕ(z)dz=12.

Lo comprobamos también por simulación.

def fZ(z):
    """Densidad analítica de Z (soporte z>0)."""
    z = np.asarray(z, float)
    return np.where(z > 0, (2*z*phi(z**2) + phi(z)), 0.0)

Z = h(X)

# Verificaciones numéricas
int_fZ, _ = integrate.quad(fZ, 0, np.inf)
F_Z = lambda z: Phi(z**2) + Phi(z) - 1            # CDF teórica
ks_Z = kstest(Z, F_Z)
print("Comprobación de f_Z:")
print(f"  soporte: min(Z) = {Z.min():.2e} > 0,  max(Z) = {Z.max():.2f}  (Z toma valores positivos) ✓")
print(f"  ∫₀^∞ f_Z(z) dz = {int_fZ:.6f}  (debe ser 1) ✓")
print(f"  test KS simulación vs F_Z teórica → D = {ks_Z.statistic:.5f} (ínfimo) ✓")

Conclusiones¶

Todas las afirmaciones numéricas proceden de las celdas ejecutadas (semilla fija).

Apartado 2.1 — fY por simulación y continuidad.

  • Y es una variable continua para todo α≠0.
  • En α=0 la rama x≥0 colapsa en y=0 y crea un átomo P(Y=0)=12: Y es mixta, no continua.
  • En α=1, Y=|X| es una media normal.
  • Frente a la normal, solo α=−1 reproduce N(0,1) (pues g(x)=−x); el test KS confirma distancia ínfima.

Apartado 2.2 — fY analítica para α>0. Vía P(Y<y)=Φ(y/α)+Φ(y)−1, fY(y)=ϕ(y)+1αϕ(yα),y>0. Integra 1 y el test KS frente a la simulación da distancia ínfima.

Apartado 2.3 — fZ. Vía P(Z<z)=Φ(z2)+Φ(z)−1, fZ(z)=2zϕ(z2)+ϕ(z)=12π(2ze−z4/2+e−z2/2),z>0, tal como pedía el enunciado. La simulación lo confirma: Z>0, la densidad integra 1 y el ajuste histograma–curva es excelente.

Idea transversal. Para transformaciones definidas a tramos, el método robusto es acumular probabilidad (P(·<v)) sumando la contribución de cada rama y derivar; cada rama monótona aporta un término ϕ(·)|jacobiano|. La simulación (histograma + KS) sirve como verificación independiente de la deducción analítica.
