# Recursos tipográficos

Benton Sans BBVA Book, Medium y Bold, obtenidas del servidor oficial de BBVA.
`font-sources.json` conserva las URL de procedencia y los SHA-256 de los originales.
Las fuentes mantienen su titularidad y no se presentan como recursos de licencia abierta.

`style_mobile_html.py` las incorpora como WOFF2 dentro del HTML. El documento no
realiza peticiones a BBVA ni usa su logotipo. Las matemáticas usan trazos SVG de
MathJax, independientes de la tipografía del cuerpo y del motor MathML del visor.
